# TIL — Today I Learned

その日に学んだことを記録するリポジトリです。
小さな発見や試行錯誤も、後から振り返れるように残します。

## 記録方法

- `YYYY/MM/DD.md` に、その日学んだことを Markdown で記録します。
- 内容に応じて見出しを分け、参考資料のリンクやコード例も添えます。
- 後から分かったことや訂正は、元の記録に追記します。
- 公開できる内容のみ記録し、認証情報・個人情報・業務上の機密情報は含めません。

## 記録の例

```markdown
# YYYY-MM-DD

## 学んだこと

- 今日の発見や理解したこと

## 試したこと

- 手順、結果、つまずいた点

## 参考資料

- [資料名](URL)
```
